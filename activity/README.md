# Activity

Every 15 minutes, the notch opens and asks what you did in that window. Pick a category and, if you like, add a short note. Over the day you get an honest picture of where your time went.

## Categories

- **Deep work**
- **Learning / planning**
- **Break / did nothing**
- **Other**

## How it works

- The check-ins run on a fixed schedule, whether or not you answer straight away.
- If you're away, the prompt pops up once and waits. It doesn't pile up repeat pop-ups.
- Change the interval with the **Window** field on the Log tab (1 to 120 minutes).

## Tabs

- **Log**: answer the current check-in with a category and an optional note.
- **Today**: a 24-hour grid of 15-minute squares, coloured by category, plus today's entries.
- **Insights**: total time logged today and the share for each category.

## Dashboard

Click the chart icon at the top right of the page. The plugin writes `dashboard.html` to its data folder and opens it in your browser. It shows all-time totals by category, and for each day the total time, the time per category, and every entry.

## Data

Entries are saved in `%APPDATA%\Fenn\plugin-data\activity\activity.json`.
